After importing this project to your VS Code , for Successful Implementation
1. Create a Virtual Environment by giving the command : python -m venv shopperstop-final1
2. Activate it : shopperstop-final1\Scripts\Activate.ps1
3. Install all Requirements : pip install -r requirements.txt
4. And run the server : uvicorn app.main:app --reload

After successful running of the project go to http://127.0.0.1:8000/docs for verification of all routes. This Interface was given by SwaggerUI.
